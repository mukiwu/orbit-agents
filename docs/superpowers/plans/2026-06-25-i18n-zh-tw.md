# 繁體中文 i18n Implementation Plan (Stream B)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 為 Orbit Agents 加上 English + 繁體中文雙語，可在 app 內即時切換、預設跟隨系統語言，renderer 與 main process 共用同一份翻譯。

**Architecture:** react-i18next 驅動 renderer；main process 用一個輕量 translator 讀同一份 `src/shared/locales/*.json`。一個純函式 `resolveLocale(pref, systemLocale)` 決定有效語系，main 與 renderer 共用。字串以英文 key 為基準、命名空間分組，逐 component 抽取。

**Tech Stack:** react-i18next、i18next、既有 vitest、electron-vite

對應 spec:`docs/superpowers/specs/2026-06-25-i18n-zh-tw-design.md`

## Global Constraints

- 雙語只做 `en` 與 `zh-TW`；架構要讓之後加語系容易（不要把語系寫死成布林）
- 整個 app 只有一份翻譯來源：`src/shared/locales/en.json` 與 `src/shared/locales/zh-TW.json`，renderer 與 main 都讀它
- `en.json` 與 `zh-TW.json` 的 key 集合必須完全一致（有測試守）
- key 以英文為基準、用命名空間：`common.* / app.* / taskForm.* / settings.* / executionLog.* / taskList.* / welcome.* / main.*`
- 不翻譯 AI-facing 的 prompt 指示（scheduler 塞給 AI 的 email/knowledge 標記、unattended 指示）
- 繁中翻譯用自然的台灣正體中文 UI 用語；避免破折號
- 純函式（resolveLocale、main translator、key 一致性）用 vitest TDD；UI 字串替換用 build + 實跑驗證
- conventional commit；不加 Co-Authored-By trailer
- 不得用 `git add -A` / `git add .`，每個 task 只 stage 自己的檔
- 文件內文不用破折號、不用引號標詞、句尾不加句號（程式碼區塊不受限）

Create `src/shared/i18n/resolveLocale.ts`:
```ts
export type LanguagePreference = 'system' | 'en' | 'zh-TW'
export type ResolvedLocale = 'en' | 'zh-TW'

export function resolveLocale(pref: LanguagePreference, systemLocale: string): ResolvedLocale {
  if (pref === 'en' || pref === 'zh-TW') return pref
  const lc = (systemLocale || '').toLowerCase()
  if (lc.startsWith('zh')) return 'zh-TW'
  return 'en'
}
```

```ts
import { describe, it, expect } from 'vitest'
import en from './en.json'
import zhTW from './zh-TW.json'

function flattenKeys(obj: Record<string, unknown>, prefix = ''): string[] {
  return Object.entries(obj).flatMap(([k, v]) => {
    const key = prefix ? `${prefix}.${k}` : k
    return v && typeof v === 'object' && !Array.isArray(v)
      ? flattenKeys(v as Record<string, unknown>, key)
      : [key]
  })
}

describe('locale resource parity', () => {
  it('en and zh-TW have identical key sets', () => {
    const enKeys = flattenKeys(en).sort()
    const zhKeys = flattenKeys(zhTW).sort()
    expect(zhKeys).toEqual(enKeys)
  })
})
```

- [ ] **Step 1: 建立 i18n 初始化**

Create `src/renderer/src/i18n.ts`:
```ts
import i18n from 'i18next'
import { initReactI18next } from 'react-i18next'
import en from '../../shared/locales/en.json'
import zhTW from '../../shared/locales/zh-TW.json'
import { resolveLocale, type LanguagePreference } from '../../shared/i18n/resolveLocale'

i18n.use(initReactI18next).init({
  resources: {
    en: { translation: en },
    'zh-TW': { translation: zhTW }
  },
  lng: resolveLocale('system', navigator.language),
  fallbackLng: 'en',
  interpolation: { escapeValue: false }
})

// Called by App after reading the persisted language preference (Electron only).
export function applyLanguagePreference(pref: LanguagePreference): void {
  i18n.changeLanguage(resolveLocale(pref, navigator.language))
}

export default i18n
```

- [ ] **Step 4: 實作 translator**

Create `src/main/i18n.ts`:
```ts
import en from '../shared/locales/en.json'
import zhTW from '../shared/locales/zh-TW.json'
import type { ResolvedLocale } from '../shared/i18n/resolveLocale'

const resources: Record<ResolvedLocale, Record<string, unknown>> = { en, 'zh-TW': zhTW }
let current: ResolvedLocale = 'en'

export function setMainLocale(locale: ResolvedLocale): void {
  current = locale
}

function lookup(obj: Record<string, unknown>, key: string): string | undefined {
  const val = key.split('.').reduce<unknown>((acc, k) =>
    acc && typeof acc === 'object' ? (acc as Record<string, unknown>)[k] : undefined, obj)
  return typeof val === 'string' ? val : undefined
}

export function t(key: string, vars?: Record<string, string | number>): string {
  const template = lookup(resources[current], key) ?? lookup(resources.en, key) ?? key
  if (!vars) return template
  return template.replace(/\{\{(\w+)\}\}/g, (_, name) =>
    name in vars ? String(vars[name]) : `{{${name}}}`)
}
```
